# Frontend state classification

## Shared state owner

[frontend/src/components/layout/AppShell.jsx](../../../frontend/src/components/layout/AppShell.jsx) exports AppShellContext and AppShell; [frontend/src/App.jsx](../../../frontend/src/App.jsx) wraps route elements in AppShell. The context value statically includes catalog, navigation categories, user, notifications, wishlist and its error/loading/sync/toggle operations, cart and add/change/remove operations, and auth/logout operations.
