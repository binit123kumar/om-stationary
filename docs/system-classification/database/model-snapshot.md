# EF Core model snapshot

**Source:** [`OmDbContextModelSnapshot.cs`](../../../backend/OMStationary.Api/Migrations/OmDbContextModelSnapshot.cs).

This is generated EF Core model metadata for migration comparison. It represents the model captured by the repository's latest generated snapshot; it is not a query of the current database. Entity/table and column reports in this area are cross-checked against `Models.cs` and `OmDbContext.cs`, which are the primary mapping sources for this static documentation.

The snapshot does not prove that it matches the deployed assembly, that a migration was applied, or that the live schema conforms. No EF model-diff, migration, or database operation was run for this task.
