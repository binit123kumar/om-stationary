## Cross-layer references and unmapped behavior

Frontend requests are inventoried in [frontend/HTTP_CALL_INVENTORY.md](frontend/HTTP_CALL_INVENTORY.md), with feature-level caller-to-action mappings in [FRONTEND_BACKEND_DATABASE_MAPPING.md](FRONTEND_BACKEND_DATABASE_MAPPING.md). The checked-in source includes two important gaps: UPI status is marked `verified=false` rather than verified with an external provider, and there is no dedicated provider-side refund operation. See [unconnected features](UNCONNECTED_FEATURES.md) and [missing implementations](MISSING_IMPLEMENTATIONS.md).

Authorization annotations and route templates are declarations; effective middleware behavior was not tested in this documentation pass. API availability and live responses are **NOT TESTED**; see [runtime status](RUNTIME_TEST_STATUS.md).
